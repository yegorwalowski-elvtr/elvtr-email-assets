# elvtr-email-assets

Static image assets for ELVTR email templates, served via jsDelivr CDN.

URL pattern: `https://cdn.jsdelivr.net/gh/yegorwalowski-elvtr/elvtr-email-assets@main/<path>`

- `student-care/` — Student Care email pack assets (icons, PM photos, social strip).

Per-cohort rendered assets (onboarding headers) also land here under `student-care/headers/`.
